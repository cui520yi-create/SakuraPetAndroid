# 银发樱花桌宠 Android 项目

## 当前实现
- 使用用户提供的角色图制作桌宠素材（对边缘连通的白色背景做透明化处理）。
- Android 悬浮窗，可拖动；轻点角色触发动作；长按角色打开控制菜单。
- 动作：拔刀式侧摆、剑气冲刺式位移、旋身、转身、蓄力姿态（当前以程序动画表现）。
- 互动：投喂团子、摸摸头、夸夸；好感度/饱食度在当前服务生命周期内累计。
- 前台服务常驻；重启广播尝试恢复服务（仍需系统允许自启动/后台运行）。

## 构建 APK
此交付环境没有 Android SDK、Gradle 或 adb，因此不能在这里编译、签名或实机验证 APK。请用 Android Studio：
1. 安装 Android Studio（建议稳定版）和 Android SDK Platform 35。
2. 打开本文件夹 `SakuraPetAndroid`，等待 Gradle Sync。
3. 选择 Build > Build Bundle(s) / APK(s) > Build APK(s)。
4. 调试 APK 通常输出在 `app/build/outputs/apk/debug/app-debug.apk`。
5. 如需正式发布，使用 Build > Generate Signed Bundle / APK 创建自己的签名密钥并生成 release APK。

## 手机上首次使用
1. 安装 APK，打开“银发樱花桌宠”。
2. 点“开启悬浮窗权限”，在系统设置中允许显示在其他应用上层。
3. 返回应用，点“启动桌宠”。
4. 长按角色打开互动菜单；拖动角色调整位置；轻点角色触发帅气动作。
5. 若希望重启后自动出现，请在手机系统设置中允许该应用自启动、后台运行，并关闭对它的电池优化限制（不同品牌入口不同）。

## 重要说明
- Android 13+ 通知权限可能需要在系统设置中允许，以便显示前台服务通知。
- Android 14/15/16 对前台服务、后台启动和特殊用途服务有额外限制；不同厂商 ROM 对开机自启的限制也不同。本项目实现了开机广播恢复逻辑，但不能保证所有机型都允许无感自启。
- 角色原图是单张静态立绘；当前动作由整体缩放、旋转、位移模拟，不是逐帧骨骼动画。若要真正拔刀、挥刀、手持食物等，需要额外绘制动作帧/分层素材。
